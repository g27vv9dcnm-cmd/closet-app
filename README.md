# クローゼット帳（服の管理アプリ・デモ）

**デモ：** https://g27vv9dcnm-cmd.github.io/closet-app/ （iPhone の Safari で見るのがおすすめです）

持っている服を登録して、着た回数を記録し、服の写真から作った3Dモデルを回して見られる Web アプリです。

## できること
- 服の登録（名前・カテゴリ・値段・購入日・色・写真・3Dモデル）
- 「今日着た」ボタンで着た回数を記録し、「1回あたりの値段」を自動で計算
- 30日以上着ていない服の一覧
- 服の表・裏・横の写真から、スマホの中だけで簡易3Dモデルを作る（外部の有料AIは使わず、1着0円）
- 3Dモデルを指で回して見る

デモには見本の服が入っています。「3D」の印がある服を開いて「3Dで見る」を押してください。

## しくみ
- HTML / CSS / JavaScript の1ファイル（サーバーなし）
- データは見る人のブラウザの中（IndexedDB）にだけ保存され、外には送られません
- 3D表示：model-viewer、3Dの作成：Three.js（写真の切り抜き → 横の写真の影絵で厚みを決める → GLB に書き出し）

## 作り方について
このアプリは、AI（Claude）に指示を出しながら作りました。
私が担当したのは、何を作るか・どの方法にするか・費用をいくらまでかけるかを決めること、iPhone で実際に試して直す所を見つけること、AI への頼み方（役割分担・合格の決め方）を工夫することです。

- 外部の3D生成AIの料金を調べ、1着40円で売る想定では赤字になるものが多いと分かったため、0円で動く方法を中心にしました。
- 品質は感覚ではなく、120着の写真で直す前と後の数字を比べて確かめました（横から見た形の重なり率 0.754 → 0.835）。

開発環境：Windows の Surface と iPhone 13
